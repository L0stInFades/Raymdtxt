# 墨 Raymdtxt

*A place where thought meets the page without friction — where markdown dissolves into meaning, and the writer is left alone with words.*

There is a particular silence that exists when the interface disappears. No split panes dividing attention. No syntax cluttering the view. Just you, your thoughts, and the quiet transformation of symbols into form. **墨** does not stand between you and your writing. It becomes invisible — the way good ink becomes the word itself.

## What It Is

A markdown editor for those who believe writing is not about tooling, but about presence. What you type is what you see — rendered in the same breath it was written.

**Harmony through simplicity:** CommonMark, GitHub Flavored Markdown, and a gentle touch of Pandoc.
**Stillness in the interface:** WYSIWYG that breathes — no preview pane, no context switch.
**Six contemplations:** Cadmium Light, Dark, Graphite Light, Material Dark, Ulysses Light, One Dark.

## The Essence

Three modes, one intention:
- **Source Code** — The raw form, for when you want to see the bones
- **Typewriter** — The present line stays centered, like a meditation bell
- **Focus** — Everything fades but the current paragraph, like fog around a single tree

## The Practice

### To Begin
```bash
# Clone the stillness
git clone https://github.com/L0stInFades/Raymdtxt.git
cd Raymdtxt

# Gather what is needed
npm install

# Enter the space
npm run electron:dev
```

### To Build
```bash
# The complete form
npm run electron:build
```

## Architecture (The Bones)

- **muya** — The editor engine, where keystrokes become structure
- **renderer** — The Vue surface, where structure becomes visible
- **main** — The Electron shell, where the window holds the world

Built with Electron, Vue.js, and the Muya editing engine.
